# Style & Design Notes

## Presentation Style Preferences

### Mode
- **Light mode** (NOT dark mode)
- Clean, bright backgrounds
- High contrast text

### Brand
- Reference "AI from the Inside" brand folder
- Use brand colors consistently
- Maintain brand typography

### Tone
- Professional but approachable
- Not corporate-stiff
- Conversational, like explaining to a friend
- Use humor where appropriate (memes, light-hearted rules)

---

## Slide Design Principles

### Layout
- Clean, uncluttered
- Plenty of white space
- One main idea per slide
- Avoid text walls

### Typography
- Large, readable fonts
- Hierarchy: Title > Subtitle > Body
- Consistent sizing throughout
- Sans-serif preferred for readability

### Colors
- Primary brand color for headers/accents
- Neutral backgrounds (white/light gray)
- Accent colors for highlights and callouts
- Consistent color meaning (e.g., green = good, red = warning)

### Images
- High quality, relevant
- Full-bleed where appropriate
- Subtle shadows/borders if needed
- No cheesy stock photos

### Charts/Data
- Simple, clear visualizations
- Minimal chart junk
- Direct labeling when possible
- Consistent color coding

---

## Content Style

### Headlines
- Action-oriented or question-based
- Provocative when appropriate
- Not just topic labels

**Good:**
- "You're No Longer the Glue"
- "What If You Had Your Own JARVIS?"
- "58% of You Worry About Privacy"

**Bad:**
- "Agent Architecture"
- "Survey Results"
- "Introduction"

### Bullet Points
- Parallel structure
- Start with verbs or nouns consistently
- Keep to one line when possible
- Max 5-6 bullets per slide

### Quotes
- Large, prominent
- Clear attribution
- Visual quote marks or callout styling

---

## Specific Element Guidelines

### Survey Data Slides
- Make the data visual (charts, icons)
- Highlight key numbers
- Include direct quotes for color
- Show we listened

### Theory Slides
- Visual diagrams over text
- Build complexity gradually
- Use consistent iconography
- Animation/transitions for reveals

### Demo Slides
- Simple prompts ("Watch this...")
- Screenshots/visuals of what they'll see
- Clear labels
- Minimal text — the demo speaks

### Closing Slides
- Clean, impactful
- Final quote prominent
- Contact/follow-up info if needed

---

## Animation/Transitions

### Preferred
- Simple fades
- Subtle builds
- Reveal animations (like human → agent comparison)
- Click-to-advance for demo sections

### Avoid
- Spinning/flying objects
- Excessive motion
- Distracting transitions between slides
- Sound effects

### Key Animation Requirement
**Slide 3.3 (Human vs Agent):**
- First click: Show human architecture only
- Second click: Reveal agent architecture alongside
- Purpose: Show the parallel before contrasting

- Full-width for hero images

- Flaticon/similar for consistent icons
- Simple shapes over complex illustrations

## Accessibility

- High contrast for readability
- No color-only information
- Large enough fonts for back of room
- Clear visual hierarchy
