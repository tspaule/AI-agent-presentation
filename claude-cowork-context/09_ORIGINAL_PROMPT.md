This is the original prompt provided for Claude Cowork to create the presentation:

---

Create a powerpoint presentation deck, in the style of AI from the Inside (reference the brand folder to see what you can learn from the images attached on style guide for the presentation). Preference 'light mode' not 'dark mode' for a presentation outline - but use the band colours and style to create the base powerpoint template.

The high level flow for the presentation should be:
1. Scene setting and agenda for the talk
2. Play back of attendee survey
3. Theory: WTF are AI Agent?: 'The building blocks of an Agent'
4. Practical: Agents doing real work: 'My Daily Use Cases'
5. Questions & Discussion

Let's break down each section of the presentation on what I'm trying to achieve:

**Scene setting and agenda:** Based on the contents, come up with background, purpose and a high level agenda in a slide. Also include some rules of engagement (no heckling, raise hands for questions so we have some order, etc. Do this in a light hearted way).

**Play back of attendee survey:** To build the slides for this section, reference the data in the AI Agent Session Intake Form excel document which has the results from the survey. Create a number of engaging slides to show the attendees we listened to their feedback on what is about to be covered and crafted the presentation around their needs.

**Theory:** Cover what an agent is and the building blocks of an agent. Make sure to compare how we build an agent to how we build a human. Reference the folder "Building blocks of an agent" including the side by side image of an human vs. an agent. Create a transition in the slide which only shows the human architecture side of the slide and then reveals the agent architecture alongside it when the slide is transitioned. In this section, present the overall breakdown and then an individual slide on each of the sections (Skills, Tool Calling, Context, Memory). For the skills section, reference skills databases online that allow you to download skills and plug them in to agents. You can also write your own skills, which we can cover in the demo if people are interested. Include the image of the Matrix where Neo is having Kung Fu uploaded, located in the folder structure you have access to.

At the end of this theory section have a slide called 'The big leap' outline how AI has moved from chatbots (question / answer) to agents (chain of thought, access to tools and skills, to manage complex workflows). Outline that the change here is the human is no longer needing to be the glue between prompts and outputs. We once had to 'jockey' the system, now the system can run end to end for us.

**Practical:** First, let's have a slide on the chosen tech stack. Claude and Claude code are now the market leaders. Show the meme of the man looking back from ChatGPT to Claude. Once this is established, let's run through some demo's of tooling. Start with Claude Code to demonstrate chain of thought, to-dos and skills in action. Outline how we create a prototype and specifications document in github, then point the agent at it. Show 26,000 lines of code written overnight in a demo. Key point - improvements are becoming 'recursive'. Software is building software to speed up the change curve. This is moving at a pace I've never seen before - towards AGI. Show a J Curve graphic to illustrate this. Next lets show Claude Cowork - in action, perhaps use the creation of the presentation deck for tonight as the use case. Local folder structure with all context loaded, then clear prompt instructions and watch the agent run its chain of thought and to-do list to complete. The final demonstration should be the JackalBot, my agent variation of ClawdBot (now OpenClaw). Open this section of the presentation with the image of Tony Stark with Jarvis, located in the folder structure you have access to. Run explain how JackalBot is constructed and where it sits (cloud hosted in Digital Ocean, not on local machine for security). Explain how this agent can be configured with skills and tool calling (do this demo in real time in the Discord thread). Explain why we use Discord to chat to JackalBot (it needs an interface to send data back and forth to the server). Some neat demos are me sending it a voice note, then processing it and emailing everyone in the room with the chosen task. Explain the power of having your own agent, but the risks too. The more data and tooling you give it access to, the more the risk of something going wrong without correct configuration or security. Explain that one attack vector was the skills databases online, people were uploading malware into it. This is a major security risk if you are giving it email and other elevated permissions (give examples).

**Questions and Discussion:** Create a 'Thank you slide' with an offer for Questions and Discussion. Make a final point on this slide "Today is the worst AI will ever be. It's only going to get better from here".
