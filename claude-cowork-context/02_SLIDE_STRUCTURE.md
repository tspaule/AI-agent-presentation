## SECTION 3: Theory — WTF Are AI Agents?
**~12-14 slides**

### Slide 3.1: Section Title
- **Title:** WTF Are AI Agents?
- **Subtitle:** The Seven Building Blocks of an Agent
- **Visual:** Clean section divider

### Slide 3.2: The Seven Building Blocks (Overview)
- **Title:** The Seven Building Blocks
- **Content:**
  1. 🧠 **Model** — The Brain
  2. 📋 **Instructions** — The Identity & Rules
  3. ⚡ **Skills** — The Learned Capabilities
  4. 🔧 **Tools** — The Actions It Can Take
  5. 📥 **Context** — The Task-Specific Information
  6. 💾 **Memory** — Persistence Across Interactions
  7. 🎯 **Orchestration** — The Planning & Sequencing Layer
- **Visual:** Stacked diagram showing the seven layers
- **Message:** "Master these seven, and you understand agents"

### Slide 3.3: Building Block 1 — Model (The Brain)
- **Title:** Model — The Brain
- **Subtitle:** The underlying AI that reasons and generates
- **Content:**
  - Determines raw intelligence, speed, and cost
  - **Key insight:** Not every task needs the most powerful model
  - Sometimes fast and cheap beats slow and brilliant
- **Example:** "Claude Opus for complex financial analysis vs. Claude Haiku for simple transaction categorisation"
- **Visual:** Brain icon or model comparison chart

### Slide 3.4: Building Block 2 — Instructions (Identity & Rules)
- **Title:** Instructions — The Identity & Rules
- **Subtitle:** Who the agent is and how it behaves
- **Content:**
  - Persistent definitions that don't change between tasks
  - The agent's personality, standards, and guardrails
- **Example:** "You are a senior financial controller. Be precise and conservative. Always flag discrepancies over $500. Never auto-approve payments above $10,000. Communicate in plain English, not accounting jargon."
- **Visual:** ID card or rulebook icon

### Slide 3.5: Building Block 3 — Skills (Learned Capabilities)
- **Title:** Skills — The Learned Capabilities
- **Subtitle:** Packaged expertise with knowledge, judgment, and process
- **Content:**
  - Skills define what the agent **knows how to do**
  - Not just access — expertise with judgment
  - Can be built-in, taught, or learned over time
  - Like uploading kung fu to Neo's brain
- **Example:** "Month-end reconciliation — the agent knows the steps, the sequence, what to check, what exceptions look like, and when to escalate"
- **Visual:** Matrix "I know kung fu" image

### Slide 3.6: Building Block 4 — Tools (Actions)
- **Title:** Tools — The Actions It Can Take
- **Subtitle:** Discrete, single-purpose actions
- **Content:**
  - **Tools are the verbs** — each one does one thing
  - Give the agent ability to interact with the outside world
  - Carry NO judgment about when or why to use them
- **Examples:** "Search the web. Query a database. Send an email. Read a bank feed. Create a document. Post a journal entry."
- **Visual:** Toolbox or API connection diagram

### Slide 3.7: Skills vs Tools — The Difference
- **Title:** Skills vs Tools
- **Subtitle:** Expertise vs Actions
- **Content:**
  | Skills | Tools |
  |--------|-------|
  | HOW to do something | WHAT to interact with |
  | Judgment & process | Single actions |
  | "Know how to reconcile" | "Can read a bank feed" |
- **Message:** "Skills use Tools, but add judgment about when and how"
- **Visual:** Side-by-side comparison

### Slide 3.8: Building Block 5 — Context (Task-Specific Info)
- **Title:** Context — The Task-Specific Information
- **Subtitle:** What's on the desk right now
- **Content:**
  - Dynamic, relevant information for THIS particular job
  - Changes every time
  - Makes the agent's work specific rather than generic
  - Your pain point: "copying and pasting into GPT" — context fixes this
- **Example:** "Here's the client's chart of accounts, this month's 247 bank transactions, and their preference for cash-basis accounting. Their fiscal year ends in June."
- **Visual:** Desk with documents or data flow diagram

### Slide 3.9: Building Block 6 — Memory (Persistence)
- **Title:** Memory — Persistence Across Interactions
- **Subtitle:** What the agent retains and applies to future sessions
- **Content:**
  - Turns every interaction from a cold start into a continuation
  - How the agent builds familiarity, learns preferences, avoids repeating mistakes
- **Example:** "Remembering that this client always miscodes contractor payments to 'office supplies,' so the agent proactively flags and reclassifies them without being told."
- **Visual:** Brain/memory icon or timeline showing continuity

### Slide 3.10: Building Block 7 — Orchestration (Planning)
- **Title:** Orchestration — The Planning & Sequencing Layer
- **Subtitle:** How the agent decides what to do, in what order
- **Content:**
  - The difference between following a fixed script and dynamically reasoning
  - What turns a collection of capabilities into coherent work
  - Plans, sequences, adapts when things change
- **Example:** "New client onboarding: gather documents → set up chart of accounts → connect bank feeds → run categorisation → flag exceptions — adjusting if something fails."
- **Visual:** Flowchart or planning diagram with decision points

### Slide 3.11: The Big Leap
- **Title:** The Big Leap
- **Subtitle:** From Chatbots to Agents
- **Content:**
  - **Before (Chatbot):** Question → Answer → Question → Answer
    - You are the glue between prompts and outputs
    - You "jockey" the system
  - **Now (Agent):** Goal → Chain of thought → Tool use → Completion
    - The agent runs end-to-end
    - Multi-step workflows without human intervention
- **Visual:** Two diagrams showing the before/after
- **Key message:** "You're no longer the glue"

### Slide 3.9: Transition to Practical
- **Title:** Theory ✓ — Now Let's See It In Action
- **Visual:** Simple transition slide to demos section
