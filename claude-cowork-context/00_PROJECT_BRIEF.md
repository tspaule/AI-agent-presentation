# Mander AI Presentation — Project Brief

## Overview
**Event:** AI Agent Session — Mander Beer & Learn
**Presenter:** Thomas Paule
**Format:** Casual beer & learn session with colleagues/friends
**Duration:** ~60-75 minutes
**Date:** February 2026

## Purpose
Educate attendees on what AI Agents are, how they work, and demonstrate practical use cases. The audience ranges from occasional AI users to daily power users, with primary concerns around privacy/security, accuracy, and not knowing where to start.

## Presentation Style
- **Mode:** Light mode (not dark mode)
- **Brand:** AI from the Inside (reference brand folder for style guide)
- **Tone:** Accessible, engaging, practical — not overly corporate
- **Visuals:** Use provided reference images (Iron Man/JARVIS, Matrix, memes)

## High-Level Flow

1. **Scene Setting & Agenda** (~5 mins)
   - Background, purpose, agenda
   - Rules of engagement (light-hearted)

2. **Survey Playback** (~5-10 mins)
   - Show attendees we listened
   - Highlight key themes from their responses

3. **Theory: WTF Are AI Agents?** (~15 mins)
   - Building blocks of an agent
   - Human vs Agent architecture comparison
   - Individual slides on: Skills, Tool Calling, Context, Memory
   - "The Big Leap" — from chatbots to agents

4. **Practical: Agents Doing Real Work** (~25-30 mins)
   - Tech stack: Claude & Claude Code
   - Demo 1: Claude Code (chain of thought, 26k lines overnight)
   - Demo 2: Claude Cowork (building this presentation!)
   - Demo 3: JackalBot (personal AI agent)

5. **Questions & Discussion** (~10-15 mins)
   - Thank you slide
   - Final message: "Today is the worst AI will ever be"

## Key Messages to Convey

1. **AI has evolved** from Q&A chatbots → autonomous agents that complete multi-step workflows
2. **The human is no longer the glue** between prompts and outputs — agents run end-to-end
3. **Improvements are recursive** — software building software, accelerating toward AGI
4. **Practical security matters** — more data/tools = more risk if misconfigured
5. **Today is the worst AI will ever be** — it only gets better from here

## Attendee Context
- 12 survey respondents
- Mix of daily users (5) and occasional users (7)
- Top concerns: Privacy/Security, Hallucinations, Not knowing where to start
- Most want balanced theory + practice (not theory-only)
- Common pain points: Email management, data reporting, context-loading tedium
